### LLM agents that stay grounded

I am an M.S. student at the [Hanyang University AI Lab](https://ai.hanyang.ac.kr/) (advisor: Prof. Yong Suk Choi, graduating February 2027). I work on three problems: keeping a persona consistent, keeping an agent's memory truthful, and checking what an agent produces before it is trusted.

**Work**

- [**TimeAware-LLM-Demo**](https://github.com/shshjhjh4455/TimeAware-LLM-Demo): a role-play agent that does not "know" events its character has not lived through yet. RoBERTa navigator, LLM verifier, streamed answers, Docker Compose.
- [**wav2vec2-base-korean**](https://huggingface.co/Kkonjeong/wav2vec2-base-korean): Korean speech recognition model, CER 0.073. 27,000+ downloads and 90+ public models fine-tuned from it. Co-developed.
- **Student GPT chat service** (2024): a pay-per-use alternative to a monthly subscription, built for university students. Six models from two providers; 316 accounts signed up.
- **lab-infra** (private): our lab's GPU-server procedures as a Claude Code plugin and a TypeScript CLI, installed with one `npx` command and used by five labmates.

**Papers**

First author at ACK 2026. Co-author at ACL 2026, EMNLP 2026 (Main and Findings) and Findings of EMNLP 2025; the list is on the [lab page](https://ai.hanyang.ac.kr/). Three first-author manuscripts are under double-blind review, so their titles and code will appear here after the decisions.
