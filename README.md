### LLM agents that stay grounded

I am an M.S. student at the [Hanyang University AI Lab](https://ai.hanyang.ac.kr/) (advisor: Prof. Yong Suk Choi), graduating in February 2027. I build and evaluate LLM agents, and I keep returning to three problems: keeping a persona consistent across a long story, keeping an agent's memory truthful, and checking what an agent produces before anyone relies on it.

**Selected work**

- [**TimeAware-LLM-Demo**](https://github.com/shshjhjh4455/TimeAware-LLM-Demo): a role-play agent that does not "know" events its character has not lived through yet. RoBERTa navigator, LLM verifier, streamed answers, Docker Compose.
- [**wav2vec2-base-korean**](https://huggingface.co/Kkonjeong/wav2vec2-base-korean): Korean speech recognition model, CER 0.073 on Zeroth-Korean. 27,000+ downloads and 90+ public models fine-tuned from it. Co-developed.
- **Student GPT chat service** (2024): a pay-per-use alternative to a monthly subscription, built for university students. Six models from two providers; 316 accounts signed up.
- **lab-infra** (private): our lab's GPU-server procedures packaged as a Claude Code plugin and a TypeScript CLI, installed with one `npx` command and used by five labmates.
